# 贪吃蛇 · Snake

一个无需构建、打开即玩的霓虹风贪吃蛇小游戏，使用原生 HTML + CSS + Canvas 实现，零依赖。

## 玩法

- 方向键 / `WASD` 控制方向，吃到红色果实得 **10 分**（随等级小幅提升）
- 每吃 4 个果实升一级，蛇的移动速度随之加快
- 出现的金色星星是限时奖励：**+50 分**，7 秒内没吃到就会消失
- 撞到墙壁（默认）或自己的身体即游戏结束；可用右上角「穿墙」开关切换成穿墙模式
- 最高分保存在浏览器 `localStorage` 中

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D`，触屏可滑动或点方向键 |
| 开始 / 暂停 / 继续 | `空格`（或点击遮罩按钮） |
| 重开 | `R` |
| 暂停 / 继续 | `P` |
| 音效开关 | 右上角「音效」按钮 |

## 本地运行

直接双击打开 `index.html` 即可（无需服务器，兼容 `file://`）。

也可以起一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 实现要点

- 20 × 20 网格，基于 `requestAnimationFrame` + 时间累加器的固定步长逻辑，速度随等级提升
- 方向输入使用长度 3 的缓冲队列，避免快速连按导致非法掉头
- Canvas 按 `devicePixelRatio` 缩放，保证高分屏清晰度
- 音效使用 Web Audio API 合成，无外部音频资源
- 页面失焦或切到后台自动暂停
